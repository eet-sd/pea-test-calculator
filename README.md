# ระบบตรวจสอบค่าบริการทดสอบ (PEA Acceptance Test Calculator)

เว็บแอปแบบ static สำหรับตอบคำถาม: พัสดุรหัสนี้/ชื่อนี้ ซื้อจำนวนเท่านี้ → ต้องทดสอบหัวข้ออะไรบ้าง สุ่มกี่ตัวอย่าง ค่าทดสอบประมาณเท่าไร

## ข้อจำกัด

- ราคา/จำนวนสุ่มเป็นไปตาม snapshot ของชีต — ตรวจสอบกับหน่วยงานทดสอบก่อนใช้อ้างอิงจริง
- รหัสที่ชีตระบุจำนวนสุ่ม "ไม่กำหนด" หน้าเว็บจะให้กรอกจำนวนสุ่มเอง
- จำนวนสุ่มถูกปรับลดไม่ให้เกินจำนวนที่ซื้อ (เช่น ตารางกำหนด 3 แต่ซื้อ 1 → สุ่ม 1 พร้อมหมายเหตุ) — ค่าที่กรอกเองในช่องจำนวนสุ่มไม่ถูกปรับ
- เฉพาะรหัสที่ชีตระบุจำนวนสุ่มเป็น "ไม่กำหนด" (ตอนนี้คือ 1020440006/1020440007) ช่อง "จำนวนตัวอย่าง" ในตารางพิมพ์ทับได้ — ค่าเริ่มต้นคือจำนวนสุ่มที่กรอกไว้, ใส่ `0` = ไม่ทดสอบ, ลบให้ว่าง = แถวนั้นไม่คิดราคา (ขึ้น `-`), กรอกเกินจำนวนสุ่มจะถูกตัดลงตอนคลิกออกจากช่อง, ค่าที่กรอกจะถูกล้างเมื่อเปลี่ยนจำนวนที่ซื้อหรือจำนวนสุ่ม รหัสอื่นแสดงจำนวนที่คำนวณให้อย่างเดียว แก้ไม่ได้
- จำนวนตัวอย่างรายหัวข้อของกลุ่ม RINS-003/2561 (1030020100/101/103) แก้ให้ตรงตาราง "ไม่ทำลาย/ทำลาย" ใน `ตรวจสอบค่าทดสอบ.docx` แล้ว (ของเดิมไม่ตรงเอกสาร) — แต่ตารางจำนวนสุ่มในชีตยังต้องแก้เป็น `<11 : 3 / 11-30 : 3 / 31-300 : 5` ไม่งั้นซื้อ 4-30 ตัวจะได้สุ่ม 5 แทน 3
- กรณีสุ่มเกิน 3 ตัวอย่างของกลุ่ม VT/CT (RMTR-021/2553) คำนวณให้แล้วใน `rules.js` (แยก 3 ตัวอย่างทดสอบ withstand/PD/inter-turn ที่เหลือทดสอบ accuracy & markings) — ใช้ได้เฉพาะกรณีจำนวนสุ่มตรงตามตาราง (5/8/13/20/32) ถ้ากรอกจำนวนสุ่มเองเป็นค่าอื่นจะคิดแบบทดสอบครบทุกตัวอย่าง
